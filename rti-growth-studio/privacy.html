Privacy Policy.

How AA Growth Studio handles submitted project enquiries, uploaded media, technical storage and external services.

Last updated: 21 October 2026

This notice describes the current live website and enquiry process. It should be reviewed whenever the studio changes the tools it uses or how it handles personal information.

1. Information we collect

When you submit the project enquiry form, we collect the information you enter: your name, business or brand, email address, mobile number, service of interest and project goals. The form also prepares a copyable project brief in your browser. Submitting the form sends the enquiry fields to the studio's CMS and saves them so the team can review and respond.

If the studio administrator uploads website images or videos, those files and basic file details are stored in the media library for use on the website. Visitors do not need to upload files to submit a project enquiry.

2. How we use information

Enquiry details are used to review your request, contact you about the project, prepare proposals and maintain related business records. We do not sell enquiry details. Please do not include passwords, payment-card information or sensitive information that is not needed to describe your project.

3. Hosting and storage

The website and CMS API are hosted using Render. Enquiry records and uploaded media are stored in a PostgreSQL database managed through Neon. These service providers process technical information as needed to host the website, run the CMS and store its data; their own terms and privacy notices also apply.

Enquiry records are available only through the authenticated studio dashboard, while media selected for the public website is served through public media URLs so that pages can display it. Do not upload confidential material as website media.

4. Retention and security

We retain enquiry information for as long as reasonably needed to respond to the request and maintain related business records. A fixed automatic deletion schedule is not currently configured, so records may remain in the database until they are no longer needed and are removed. Access to dashboard records is restricted by admin authentication. No internet service can guarantee absolute security.

5. Browser storage, cookies and analytics

The site uses session storage for the opening animation, a random visitor-session ID for the current browser tab, and first-touch attribution labels (such as UTM source, medium, campaign and landing page) so submitted enquiries can be attributed to the campaign that introduced the visitor. First-party analytics records page paths without query strings, referral hostnames, coarse device and browser category, browser language and time zone, approximate engagement duration, scroll-depth milestones, generic link/button interactions, form starts/submissions and successful lead conversions. It does not record visitor IP addresses, precise GPS coordinates, keystrokes, passwords or typed form contents as analytics; details deliberately entered into the contact form are stored securely in the enquiry dashboard so the studio can respond. The time zone and language are browser-reported hints, not a verified physical location. Analytics event collection respects the browser Do Not Track signal. The free-growth-plan popup and the full Contact form include a separate optional checkbox for Meta ad-conversion measurement. Only when that box is selected for the enquiry may the site load the Meta Pixel and send a Lead event through Meta's Conversions API. Contact details used for opted-in event matching are normalized and SHA-256 hashed before being sent to Meta; available click identifiers and browser hints may also be included. Meta then processes that measurement under its own terms and privacy policy. The Pixel and Conversions API are not used for an enquiry when that optional consent is not selected.

6. External links

Some links may open third-party websites or platforms. Those services operate under their own privacy practices, which apply when you visit them.

7. Your requests and contacting us

If you wish to ask about, correct or request deletion of information you submitted, contact the studio using the phone number displayed on the Contact page. We may need to verify the request before acting on it. The website currently has no configured enquiry email address.

8. Updates

This notice may change when the website, service providers or enquiry process changes. The date above indicates the latest revision.
